# 🦁 GStools Combat Equipment - متجر النخبة لفنون القتال

منصة تجارة إلكترونية احترافية تفاعلية وعالية الأداء مخصصة لعلامة معدات وأوقية الفنون القتالية **GStools**. مصممة بهوية داكنة شرسة مستوحاة من شعار الأسد وقفازات النزال الذهبية والفولاذ المسلح.

---

## 🚀 كيفية تشغيل المتجر

### 1. التشغيل المباشر (Direct In-Browser)
- افتح ملف `index.html` مباشرة بالنقر المزدوج في أي متصفح (Chrome, Edge, Firefox, Safari).

### 2. التشغيل عبر خادم محلي (Local Server)
```bash
node server.js
```
ثم افتح المتصفح على: `http://localhost:3000`

## 💰 الأسعار ونظام الحساب المالي
- جميع المنتجات بأسعار تنافسية ومدروسة بالجنيه المصري (**ج.م**).
- احتساب فوري لمجموع المنتجات، قيمة الخصم، مصاريف الشحن للمحافظات (50 ج.م أو **مجاني** للطلبات فوق 2000 ج.م)، والإجمالي الكلي.
- يدعم المتجر أكواد الخصم التالية:
  - `CHAMPION`: خصم 15% على إجمالي العتاد.
  - `GS10`: خصم 10%.
  - `LION`: خصم 12%.
